# Analyq Frontend

React and TypeScript frontend for Analyq.

## Local Setup

From the `frontend` directory:

```bash
npm install
```

## Run The Frontend

```bash
npm run dev
```

The app expects the backend API to run at:

```text
http://localhost:8000
```

Override this with `VITE_API_BASE_URL`.

## Build

```bash
npm run build
```
